Guía de Integración: Módulo Traversability y Memoria

Esta guía detalla los pasos conceptuales y modificaciones necesarias para que el módulo de Traversability (junto con el mapa persistente) complemente al sistema GeNIE en el archivo bridge.py, permitiendo que el robot mantenga memoria espacial y no pierda de foco el trayecto entre checkpoints.

1. Concepto de la Integración

  • Percepción Instantánea (GeNIE): Analiza el frame RGB actual del SDK para detectar obstáculos inmediatos en el campo de visión.
  • Memoria y Transitabilidad (Traversability / PersistentMap): Proyecta esa información usando odometría para acumularla en un mapa global. Esto evita que el robot "olvide" un obstáculo que acaba de salir de cuadro o pierda el rumbo hacia el objetivo.

2. Verificación de la Configuración YAML

El archivo configs/frodobot_rover.yaml debe contar con la sección memory correctamente habilitada para que el bridge active el mapa persistente:

memory:
  enabled: true
  map_size_m: 12.0          # Tamaño del mapa global en metros
  update_weight: 0.45       # Peso de actualización por frame
  decay_per_s: 0.05         # Tasa de olvido temporal
  plan_forward_m: 4.0       # Rango de planificación frontal con memoria
  plan_side_m: 3.0          # Rango lateral del planificador

3. Modificaciones en el Loop de Control (bridge.py)

Asegurate de que dentro del método _step() de tu bridge se esté aplicando correctamente la integración del mapa persistente sobre los resultados del pipeline:

# Procesamiento de percepción actual
res = self.perception.process(rgb)

# Valores por defecto basados en la percepción instantánea
plan_bev, plan_obs = res.traversability, res.observed
nota_mapa = ""

# Integración con Traversability y Memoria Espacial
if self.use_map and self.odometry is not None and self.pmap is not None:
    pose = self.odometry.update(telem.raw)
    
    # 1. Acumulamos el mapa de transitabilidad actual en la memoria global
    self.pmap.integrate(res.traversability, res.observed, pose,
                        self.forward_range, self.side_range, t=now)
    
    h, w = res.traversability.shape
    
    # 2. Extraemos la vista BEV histórica para alimentar al planificador con memoria
    plan_bev, plan_obs = self.pmap.extract_bev(
        pose, self.plan_forward_m, self.plan_side_m, h, w)
    
    st = self.pmap.stats()
    nota_mapa = f" mapa: {st['celdas_vistas']} celdas vistas"
Nota de seguridad: El chequeo de colisión frontal inmediato (front_is_blocked) debe seguir evaluando la observación fresca del frame actual, garantizando una reacción rápida ante peligros repentinos sin depender exclusivamente del promedio histórico del mapa.

4. Validación y Pruebas

Para verificar que la integración de memoria y traversability está funcionando correctamente sin arriesgar el hardware del robot, ejecutá primero el entorno en modo simulación (DRY-RUN) con directorio de depuración:

python -m genie_rover.bridge --config configs/frodobot_rover.yaml --debug-dir debug/run_test

Revisá que en la carpeta de depuración se generen correctamente los mapas históricos acumulados (*_mapa.png) junto con las vistas de planificación.
